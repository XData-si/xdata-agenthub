- **XAH-204**: restore verified after failure injection; symlink and traversal cases rejected; upgrade safety documented.
- **XAH-205**: per-client discovery/native-use/direct-read distinction; versions, OS, reproducible prompts, redacted evidence.
- **XAH-206**: CI includes schema, update, rollback and audit tests; exact release SHA recorded.
- **XAH-207**: deterministic filters and machine-readable JSON; tests for empty/malformed queries.
- **XAH-208**: output clearly distinguishes known metadata from unverified upstream claims.
- **XAH-209**: explicit opt-in, pinned source, checksum validation, offline failure behavior, no remote script execution.
- **XAH-210**: quickstart, migration, recovery and troubleshooting examples tested against actual CLI.
