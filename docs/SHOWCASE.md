# Show, don't tell

## Hero message

**Your agent stack, ready in seconds.**

Discover original skills. Inspect what they do. Install local-first. Keep control of every file.

## Demo storyboard

1. `xah list` shows the catalog.
2. `xah search security` finds relevant skills.
3. `xah inspect security-review` displays full instructions and provenance.
4. `xah init --agent claude --profile developer --target ./demo --dry-run` previews the output.
5. `xah init --agent claude --profile developer --target ./demo` writes local files.
6. Show `.claude/skills/` and `CLAUDE.md` in a code editor.

## Visual brief

Use a distinctive original XData purple accent with neutral backgrounds. Produce a 1280×640 social preview, lightweight SVG mark and an actual recorded terminal demo. Never use fabricated metrics or imply endorsements by agent vendors.

## Positioning

AgentHub is not another list of links: it is an inspectable, installable starting point. Current alpha does not yet provide remote registry syncing, semantic conversion, signed packages or independent security certification.
