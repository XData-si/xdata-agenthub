# Launch and positioning

**Tagline:** One place. Every agent capability.

**Elevator pitch:** XData AgentHub helps developers discover and install inspectable AI agent skills, instructions and workflows without committing to a single vendor. The alpha is deliberately local-first and safe by default.

**Hero CTA:** Explore the catalog · Try the CLI · Contribute a skill

**Target audience:** AI engineers, platform teams, DevOps, indie developers and technical leads.

**Messaging pillars:** portability, transparency, developer experience, security-minded curation.

**Demo script (60 seconds):** show list → search → inspect → add to fresh sample project → audit → show generated file → link to XData.

**Launch assets to prepare:** original SVG mark, social preview, terminal recording, short demo video, launch blog, contribution guide, honest FAQ.

**Suggested GitHub topics:** ai-agents, agent-skills, agents-md, claude-code, codex, opencode, developer-tools, mcp, open-source, ai-tooling.

**Trust:** no fake metrics, no purchased stars, no misleading vendor compatibility claims.
