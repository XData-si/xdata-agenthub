# Contributing

Thanks for helping build a trustworthy, portable agent toolkit.

1. Open an issue explaining the problem or proposed template.
2. For skills, submit original content or material with clearly compatible redistribution rights.
3. Include a short description, expected target, source/provenance, license, test instructions and known limitations.
4. Never submit secrets, copied proprietary prompts, obfuscated commands or unreviewed install scripts.
5. Keep pull requests focused; maintainers review security-sensitive changes before merging.

**Review checklist:** useful, understandable, correctly licensed, non-destructive, documented and testable.
